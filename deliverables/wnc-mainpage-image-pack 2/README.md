# WnC 메인페이지 이미지 팩

`main` 폴더의 파일명은 `apps/web/public/images/main`의 기존 메인페이지 이미지 파일명과 같습니다.
각 파일을 같은 이름의 기존 파일과 교체하면 됩니다.

| 파일 | 용도 |
| --- | --- |
| `main_hero_01.jpg` ~ `main_hero_03.jpg` | 상단 히어로 슬라이드 |
| `main_banner_video.jpg` | 회사 소개 뒤 영상 배너 |
| `main_project_01.jpg` ~ `main_project_04.jpg` | 프로젝트 카드 기본 이미지 |
| `main_banner_services.jpg` | 개발 철학 뒤 서비스 배너 |
| `main_service_01.jpg` ~ `main_service_03.jpg` | 서비스 카드 이미지 |
| `main_video_project.jpg` | 프로젝트 영상 배너 |

모든 파일은 1376 × 768px, JPG 형식입니다. 이미지에는 문구·로고·워터마크를 넣지 않았습니다.
